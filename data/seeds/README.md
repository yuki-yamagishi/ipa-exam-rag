## 2. データの構成と付加価値

### 2.1. 本物の試験問題と公式解答の完全網羅
本シードデータ（全125問）は、IPA（独立行政法人情報処理推進機構）が実施した**実物のシステムアーキテクト試験午前II問題（問1〜問25）**を正確に構造化・収録しています。
問題文、四肢選択肢（ア・イ・ウ・エ）、および公式正解記号が忠実に再現されています。

### 2.2. 高密度な独自技術解説とキーワード付与
公式解答例には正解の記号のみが公表されており、解説は含まれません。
本システムでは、すべての設問に以下の学習支援付加価値を付与して構造化しています：
1. **正解の論理的根拠**: なぜその選択肢が正しいのかの定義と背景。
2. **誤答選択肢の対比解説**: 他の選択肢が何を表しているのか、どこが誤りなのかの明確な技術的解説。
3. **シラバス分類 & キーワード**: 3軸フィルタリングおよび RAG ハイブリッド検索（Dense + Sparse）の精度を最大化するための構造化タグ。
