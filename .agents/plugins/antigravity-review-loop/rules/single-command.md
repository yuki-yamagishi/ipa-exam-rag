# 単一コマンド実行規約

シェルコマンド（`run_command` ツール等）を実行する際は、以下のルールを厳格に遵守すること：

1. **複数コマンドの連結禁止**:
   - PowerShell のセミコロン（`;`）や `&&`、パイプ（`|`）を用いて複数のコマンドを 1 行に連結して実行してはならない。
2. **単一コマンド実行の義務化**:
   - 1 回のツール呼び出しにつき、必ず単一のコマンド（例: `git status` のみ、`git branch -a` のみ）として個別に実行すること。
3. **目的**:
   - `settings.json` の自動実行許可（Allowlist）判定を阻害せず、セキュリティ上の誤検知や不要な確認プロンプトの発生を防ぐため。
